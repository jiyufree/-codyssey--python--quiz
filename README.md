

# 🎯 나만의 퀴즈 게임 (HSK 3급)

## 📖 1. 미션 소개
프로그래밍 언어를 배우는 가장 확실한 방법은, 동작하는 프로그램을 처음부터 끝까지 직접 만들어 보는 것입니다.
문법을 아는 것과 그 문법으로 하나의 프로그램을 완성하는 것은 전혀 다른 경험입니다.
이 미션에서는 그 차이를 직접 확인합니다.

Python과 Git은 "내가 만든 프로그램이 왜 이렇게 동작하는지"를 설명하고, 그 과정을 기록하며 성장하기 위한 핵심 도구입니다.
이 미션에서는 터미널에서 동작하는 나만의 퀴즈 게임을 처음부터 끝까지 구현합니다.
Python 기본 문법을 사용해 입력/출력 흐름을 만들고, 클래스(객체 지향)로 코드를 역할별로 구조화합니다.
아울러 JSON 파일 저장을 통해 프로그램을 종료해도 퀴즈와 점수가 유지되도록 "데이터 영속성"을 경험합니다.

또한, Git으로 변경 이력을 관리합니다.
기능 단위로 커밋하고, 브랜치를 나눠 작업한 뒤 병합하며, GitHub에 저장소를 공개합니다.
이 경험은 이후 팀 협업(브랜치 전략, PR, 코드 리뷰)으로 자연스럽게 확장됩니다.

## 🤔 2. 퀴즈 주제 선정 이유
**HSK 3급 중국어 단어**
현재 HSK 3급 시험(IBT)을 목표로 중국어를 공부하고 있습니다.
자주 헷갈리는 필수 단어와 병음, 뜻을 퀴즈 형태로 직접 출제하고 풀어봄으로써,
프로그래밍 미션 완수와 중국어 단어 암기라는 두 가지 목표를 동시에 달성하기 위해 이 주제를 선정했습니다.

## 🎯 3. 과제 목표 및 코드 구현 설명 (평가 대비용)
이 프로젝트를 통해 아래의 개념들을 직접 코드로 구현하고 설명할 수 있습니다.

### [Python 기초]
- **변수**: 퀴즈 점수를 누적하기 위해 `score = 0`이라는 변수를 사용해 데이터를 담았습니다.
- **자료형**: 숫자(`int`), 문자열(`str`), 참/거짓(`bool`), 리스트(`list`), 딕셔너리(`dict`)를 목적에 맞게 모두 활용했습니다.
- **조건문 (if/elif/else)**: 사용자의 메뉴 선택 등 조건에 따른 분기 처리에 사용했습니다.
- **반복문 (for/while)**: 메뉴 무한 반복(`while True`), 퀴즈 목록 순회(`for idx, quiz in enumerate(...)`)에 사용했습니다.
- **함수**: `def`를 사용해 기능을 분리하고, 매개변수와 반환값(`return`)을 활용해 객체 간 통신을 구현했습니다.

### [클래스와 객체]
- **클래스/객체**: 역할을 분리하기 위해 `Quiz`와 `QuizGame` 클래스를 정의하여 코드를 객체 지향적으로 구조화했습니다.
- **`__init__`과 `self`**: 생성자(`__init__`)로 객체의 초기 상태를 정의하고, `self`를 통해 객체 자신의 속성과 메서드에 접근했습니다.

### [파일 입출력]
- **파일 처리**: `with open()` 구문으로 파일을 안전하게 열고 쓰기/읽기를 수행했습니다.
- **JSON 형식**: 파이썬의 리스트/딕셔너리 구조를 그대로 저장하고 불러오기 좋은 텍스트 기반 데이터 포맷(`state.json`)을 사용했습니다.
- **예외 처리 (try/except)**: 잘못된 입력(`ValueError`)이나 파일이 없는 경우(`FileNotFoundError`) 프로그램이 비정상 종료되지 않도록 안전하게 방어했습니다.

### [Git 기초]
- **버전 관리**: `add`, `commit`, `push`, `pull`을 통해 변경 이력을 관리하고 GitHub에 동기화했습니다.
- **브랜치 활용**: 퀴즈 풀기 기능 개발 시 `feature-play` 브랜치를 생성(`checkout -b`)하여 별도 작업한 후 `main`에 병합(`merge`)했습니다.

## 📋 4. 최종 결과물 요구사항 충족
- ✅ **동작하는 퀴즈 게임**: 메뉴 기반 퀴즈 출제, 추가, 목록, 점수 확인 정상 동작 (HSK 3급 퀴즈 5개 포함)
- ✅ **코드 구조**: `Quiz`, `QuizGame` 클래스 분리 및 기능별 메서드 모듈화
- ✅ **데이터 영속성**: `state.json` (UTF-8) 파일로 데이터 저장 및 불러오기 완비
- ✅ **Git & GitHub**: 의미 있는 커밋 10개 이상, 브랜치 생성 및 병합(`checkout`, `merge`) 반영 완료
