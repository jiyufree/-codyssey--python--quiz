# 🎯 나만의 퀴즈 게임 (HSK 3급)

파이썬을 활용한 콘솔 기반 퀴즈 게임 프로젝트입니다.

## 🛠️ 기술 스택
- Python 3.10+
- JSON (데이터 영구 저장)
- Git & GitHub (버전 관리 및 브랜치 활용)

## ✨ 주요 기능
1. **퀴즈 풀기**: HSK 3급 단어 퀴즈를 풀고 점수를 확인합니다.
2. **퀴즈 추가**: 사용자가 직접 새로운 퀴즈를 추가할 수 있습니다.
3. **퀴즈 목록**: 등록된 모든 퀴즈 목록을 확인합니다.
4. **점수 확인**: 역대 최고 점수를 확인합니다.
5. **데이터 유지**: 프로그램을 종료해도 `state.json` 파일에 데이터가 안전하게 보존됩니다.

## 🚀 실행 방법
python main.py
