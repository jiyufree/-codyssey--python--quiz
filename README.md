# 🎯 나만의 퀴즈 게임 (HSK 3급)

## 📖 1. 프로젝트 개요
프로그래밍 언어를 배우는 가장 확실한 방법은, 동작하는 프로그램을 처음부터 끝까지 직접 만들어 보는 것입니다. 문법을 아는 것과 그 문법으로 하나의 프로그램을 완성하는 것은 전혀 다른 경험입니다. 이 미션에서는 그 차이를 직접 확인합니다.

Python과 Git은 "내가 만든 프로그램이 왜 이렇게 동작하는지"를 설명하고, 그 과정을 기록하며 성장하기 위한 핵심 도구입니다. 이 미션에서는 터미널에서 동작하는 나만의 퀴즈 게임을 처음부터 끝까지 구현합니다. Python 기본 문법을 사용해 입력/출력 흐름을 만들고, 클래스(객체 지향)로 코드를 역할별로 구조화합니다. 아울러 JSON 파일 저장을 통해 프로그램을 종료해도 퀴즈와 점수가 유지되도록 "데이터 영속성"을 경험합니다.

또한, Git으로 변경 이력을 관리합니다. 기능 단위로 커밋하고, 브랜치를 나눠 작업한 뒤 병합하며, GitHub에 저장소를 공개합니다. 이 경험은 이후 팀 협업(브랜치 전략, PR, 코드 리뷰)으로 자연스럽게 확장됩니다.

## 🤔 2. 퀴즈 주제 선정 이유
**HSK 3급 중국어 단어**
현재 HSK 3급 시험(IBT)을 목표로 중국어를 공부하고 있습니다. 자주 헷갈리는 필수 단어와 병음, 뜻을 퀴즈 형태로 직접 출제하고 풀어봄으로써, 프로그래밍 미션 완수와 중국어 단어 암기라는 두 가지 목표를 동시에 달성하기 위해 이 주제를 선정했습니다.
