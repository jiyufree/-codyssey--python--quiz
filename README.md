## 📖 1. 미션 소개

프로그래밍 언어를 배우는 가장 확실한 방법은, 동작하는 프로그램을 처음부터 끝까지 직접 만들어 보는 것입니다.
문법을 아는 것과 그 문법으로 하나의 프로그램을 완성하는 것은 전혀 다른 경험입니다.
이 미션에서는 그 차이를 직접 확인합니다.

Python과 Git은 "내가 만든 프로그램이 왜 이렇게 동작하는지"를 설명하고, 그 과정을 기록하며 성장하기 위한 핵심 도구입니다.
이 미션에서는 터미널에서 동작하는 나만의 퀴즈 게임을 처음부터 끝까지 구현합니다.
Python 기본 문법을 사용해 입력/출력 흐름을 만들고, 클래스(객체 지향)로 코드를 역할별로 구조화합니다.
아울러 JSON 파일 저장을 통해 프로그램을 종료해도 퀴즈와 점수가 유지되도록 "데이터 영속성"을 경험합니다.

또한, Git으로 변경 이력을 관리합니다.
기능 단위로 커밋하고, 브랜치를 나눠 작업한 뒤 병합하며, GitHub에 저장소를 공개합니다.
이 경험은 이후 팀 협업(브랜치 전략, PR, 코드 리뷰)으로 자연스럽게 확장됩니다.

## 🤔 3. 퀴즈 주제 선정 이유

**주제: HSK 3급 중국어 단어**

현재 HSK 3급 시험(IBT)을 목표로 중국어를 공부하고 있습니다.
단어장을 눈으로만 보면 **병음, 비슷하게 생긴 단어(重要 / 需要 / 主要 / 只要), 동사와 어울리는 목적어**가 자꾸 헷갈렸습니다.
그래서 헷갈리는 단어를 직접 4지선다 문제로 만들고 풀어 보면서,
**프로그래밍 미션 완수와 중국어 단어 암기라는 두 가지 목표를 동시에 달성**하기 위해 이 주제를 선정했습니다.
공부하다 틀린 단어는 메뉴 2번으로 바로 추가해 나만의 오답 노트처럼 쓸 수 있습니다.

| # | 기본 퀴즈 | 유형 |
|---|---|---|
| 1 | '도서관'을 뜻하는 단어의 병음은? | 뜻 → 병음 |
| 2 | 经常(jīngcháng)의 뜻은? | 단어 → 뜻 |
| 3 | '중요하다'를 뜻하는 단어는? | 비슷한 단어 구별 |
| 4 | 突然(tūrán)의 뜻은? | 단어 → 뜻 |
| 5 | 喝(hē, 마시다)와 어울리는 단어는? | 동사-목적어 짝꿍 |

## 🚀 4. 실행 방법

```bash
# 1. Python 버전 확인 (3.10 이상)
python --version

# 2. 저장소 복제

> 💡 `state.json`은 실행한 폴더 기준으로 읽고 저장하므로, **반드시 프로젝트 폴더 안에서 실행**합니다.

메뉴에서 **1~5 숫자**를 입력하고 Enter를 누릅니다. 정답도 **1~4 번호**로 입력합니다.

## 📋 5. 기능 목록

| 메뉴 | 기능 | 세부 동작 |
|:---:|---|---|
| 1 | **퀴즈 풀기** | 저장된 퀴즈를 순서대로 출제 → 1~4 정답 입력 → ✅ 정답 / ❌ 오답(정답 번호 안내) → 모든 문제를 풀면 "N문제 중 M문제 정답!" 표시. 최고 기록보다 많이 맞히면 🎉 갱신 후 저장. 퀴즈가 없으면 안내 후 메뉴로 |
| 2 | **퀴즈 추가** | 문제 → 선택지 1~4 → 정답 번호(1~4) 입력. 빈 입력이나 잘못된 번호면 안내 후 메뉴로 돌아감. 추가 즉시 `state.json`에 저장 |
| 3 | **퀴즈 목록** | "등록된 퀴즈 목록 (총 N개)"와 함께 번호·문제 출력. 퀴즈가 없으면 안내 |
| 4 | **점수 확인** | "최고 점수: OO점 (M문제 정답)" 출력 (1문제당 20점) |
| 5 | **종료** | 데이터 저장 후 종료 |

```
-codyssey--python--quiz/

├── README.md      # 프로젝트 설명 문서
└── .gitignore     # Git에 올리지 않을 파일 (__pycache__/ 등)

| 파일 | 역할 | 이렇게 나눈 이유 |
|---|---|---|
| `main.py` | 실행만 담당 | 프로그램이 어디서 시작하는지 한눈에 보이게 |

## 💾 7. 데이터 파일 설명 (state.json)

| 항목 | 내용 |
|---|---|
| **경로** | 프로젝트 루트의 `state.json` (main.py와 같은 폴더) |
| **인코딩** | UTF-8. `ensure_ascii=False`로 저장해 한글·한자·병음(ǎ, ī 등)이 깨지지 않음 |
| **역할** | 퀴즈 목록과 최고 점수를 저장해, 프로그램을 다시 실행해도 데이터 유지 (데이터 영속성) |
| **저장 시점** | ① 퀴즈 추가 직후 ② 최고 기록 갱신 직후 ③ 메뉴 5번 종료 시 ④ Ctrl+C/EOF 종료 시 ⑤ 기본 퀴즈로 시작할 때 |

### 스키마 (필드 구조)

| 키 | 타입 | 설명 |
|---|---|---|
| `quizzes` | list | 퀴즈 목록 |
| `quizzes[].question` | str | 문제 |
| `quizzes[].choices` | list[str] | 선택지 4개 |
| `quizzes[].answer` | int | 정답 번호 (1~4) |
| `best_score` | int | 최고 기록 (가장 많이 맞힌 문제 수). 화면에는 × 20점으로 표시 |

### 예시
```json
{
    "quizzes": [
        {
            "question": "단어 '经常(jīngcháng)'의 뜻은 무엇일까요?",
            "choices": ["가끔", "자주, 종종", "결코 ~않다", "방금"],
            "answer": 2
        }
    ],
    "best_score": 4
}
```

### 파일이 없거나 손상된 경우

| 상황 | 예외 | 처리 |
|---|---|---|
| 파일 없음 (첫 실행) | `FileNotFoundError` | 기본 퀴즈 5개로 시작하고 `state.json` 새로 생성 |
| JSON 형식이 깨짐 | `json.JSONDecodeError` | 기본 퀴즈 5개로 초기화 후 저장 |
| 저장 중 오류 | `Exception` | "데이터 저장 중 오류" 안내 후 계속 실행 |

## 🧱 8. 클래스 구조

```
┌─────────────────────────┐        ┌──────────────────────────────┐
│ Quiz  (quiz.py)         │        │ QuizGame  (game.py)          │
├─────────────────────────┤        ├──────────────────────────────┤
│ question : str          │  N개   │ quizzes   : list[Quiz]       │
│ choices  : list[str]    │◀───────│ best_score: int              │
│ answer   : int (1~4)    │  보관  │ data_file : "state.json"     │
├─────────────────────────┤        ├──────────────────────────────┤
│ display()               │        │ run()          display_menu()│
│ check_answer(n) → bool  │        │ get_user_input()             │
│ to_dict() → dict        │        │ play_quiz()    add_quiz()    │
└─────────────────────────┘        │ show_list()    show_score()  │
                                   │ load_data()    save_data()   │
                                   │ setup_default_quizzes()      │
                                   └──────────────────────────────┘
```

| 분류 | 메서드 | 하는 일 |
|---|---|---|
| 입력 처리 | `get_user_input()` | 메뉴 번호 입력·검증 (공백, 빈 입력, 문자, 범위 밖) |
| 게임 진행 | `run()` | 메뉴를 반복하며 번호에 맞는 기능 호출 |
| | `display_menu()` | 메뉴 화면 출력 |
| | `play_quiz()` | 출제 → 정답 입력·검증 → 채점 → 결과, 최고 기록 갱신 |
| 기능 | `add_quiz()`, `show_list()`, `show_score()` | 추가 / 목록 / 점수 확인 |
| 저장 | `load_data()`, `save_data()`, `setup_default_quizzes()` | 불러오기 / 저장 / 기본 퀴즈 생성 |

## 🛡️ 9. 입력/예외 처리

| 입력 예 | 결과 |
|---|---|
| ` 1 ` (앞뒤 공백) | `.strip()`으로 공백 제거 후 1로 처리 |

## 🎯 11. 과제 목표 및 코드 구현 설명

### [Python 기초]
- **변수**: 값에 이름을 붙여 저장하고 다시 쓰기 위해 사용합니다. 예) 맞힌 개수를 누적하는 `score = 0`
- **자료형**

  | 자료형 | 사용한 곳 |
  |---|---|
  | `int` | 정답 번호(1~4), 점수, 메뉴 번호 |
  | `str` | 문제, 선택지, 입력값 |
  | `bool` | `check_answer()`의 정답 여부(True/False) |
  | `list` | 선택지 4개, 퀴즈 목록 |
  | `dict` | JSON 저장용 퀴즈 데이터 |
- **조건문 (if/elif/else)**: 메뉴 번호에 따른 기능 분기, 정답/오답 판정, 최고 점수 갱신 여부
- **반복문 (for/while)**
  - `for`: 반복 횟수가 정해진 경우 → 퀴즈 목록 순회 `for idx, quiz in enumerate(self.quizzes, 1)`
  - `while`: 조건이 만족될 때까지 반복 → 메뉴 반복 `while True`, 올바른 숫자를 입력할 때까지 재입력
- **함수**: `def`로 기능을 나누고, `check_answer(user_answer)`처럼 매개변수로 값을 받아 `return`으로 결과를 돌려줍니다.

### [클래스와 객체]
- **클래스/객체**: 클래스는 데이터(속성)와 기능(메서드)을 묶은 설계도이고, 객체는 그 설계도로 만든 실제 값입니다. 퀴즈 1개는 `Quiz`, 게임 전체는 `QuizGame`으로 역할을 나눴습니다.
- **`__init__`과 `self`**: `__init__`은 객체가 만들어질 때 자동으로 실행되어 속성을 초기화합니다. `self`는 "지금 이 객체 자신"을 가리켜 `self.quizzes`, `self.save_data()`처럼 자기 속성과 메서드에 접근합니다.
- **속성과 메서드**: `Quiz`의 속성은 `question`, `choices`, `answer`, 메서드는 `display()`, `check_answer()`, `to_dict()`입니다.

### [파일 입출력]
- **파일 처리**: `with open("state.json", "r"/"w", encoding="utf-8")`로 열면 블록이 끝날 때 파일이 자동으로 닫힙니다.
- **JSON 형식**: 사람이 읽을 수 있는 텍스트 형식이고 Python의 `list`/`dict` 구조와 같아서, `json.dump()`/`json.load()`로 그대로 저장·복원할 수 있습니다.
- **예외 처리 (try/except)**: 파일 없음(`FileNotFoundError`), 파일 손상(`JSONDecodeError`), 숫자가 아닌 입력(`ValueError`), 강제 종료(`KeyboardInterrupt`, `EOFError`)를 처리해 프로그램이 비정상 종료되지 않게 했습니다.

### [Git 기초]
- **Git이 필요한 이유**: 언제, 무엇을, 왜 바꿨는지 기록이 남아 문제가 생기면 이전 상태로 돌아갈 수 있고, 여러 사람이 나눠서 작업할 수 있습니다.
- **버전 관리**: 기능을 하나 완성할 때마다 `add` → `commit` → `push`로 기록하고 GitHub에 올렸습니다.
- **브랜치**: 퀴즈 풀기 기능은 `feature-play` 브랜치를 만들어(`checkout -b`) 작업한 뒤 `main`에 병합(`merge`)했습니다.
- **clone과 pull의 차이**: clone은 원격 저장소를 처음 통째로 복사하는 것이고, pull은 이미 가진 저장소에 새로 바뀐 내용만 가져오는 것입니다.
